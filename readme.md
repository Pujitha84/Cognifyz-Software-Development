# CodeQuest - The Hacker's Trial 🔐

## Cognifyz Technologies - Software Development Internship

### Task 1: Text-Based Quiz Game

CodeQuest is a simple text-based quiz game developed in Python as part of Task 1 of the Cognifyz Technologies Software Development Internship.

The game presents the player with multiple programming and technology-related questions. The player earns points for correct answers and loses lives for incorrect answers.

## Features

* 🎮 Interactive text-based quiz
* 🧠 Programming and technology questions
* ❤️ Three lives system
* ⭐ Score tracking
* 💡 Hint option
* 🔀 Randomized question order
* 🏆 Different results based on the final score
* 🔐 Game-themed "vault" challenge

## Game Rules

1. The player starts with 3 lives.
2. Each correct answer gives 10 points.
3. An incorrect answer costs 1 life.
4. The player can enter `H` to receive a hint.
5. The game ends when all questions are completed or all lives are lost.
6. The final result depends on the player's score.

## Technologies Used

* Python
* Conditional statements
* Loops
* Lists and dictionaries
* User input
* Random module

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in a terminal.
3. Run:

```bash
python codequest.py
```

4. Follow the instructions displayed in the terminal.

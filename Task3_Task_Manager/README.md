# Task Manager - CRUD Application 📋

## Cognifyz Technologies - Software Development Internship

### Level 2: Intermediate — Task 3

This project is a console-based **Task Manager application** developed in Python as part of Task 3 of the Cognifyz Technologies Software Development Internship.

The application performs basic **CRUD operations** on a list of tasks.

## Features

* Create new tasks
* View all existing tasks
* Update task details
* Delete tasks
* Task status tracking
* Interactive console menu
* Input validation

## CRUD Operations

### Create

Allows the user to create a new task by entering:

* Task title
* Task description

Each task is assigned a unique Task ID.

### Read

Displays all tasks stored in the task list, including:

* Task ID
* Title
* Description
* Status

### Update

Allows the user to modify:

* Task title
* Task description
* Task status

### Delete

Allows the user to delete a task using its Task ID.

## How to Run

1. Open a terminal in the project folder.
2. Run:

```bash
python task_manager.py
```

3. Select an option from the menu:

```text
1. Create Task
2. View Tasks
3. Update Task
4. Delete Task
5. Exit
```

# 🌡️ Temperature Converter

## 📌 Cognifyz Technologies — Software Development Internship

**Task 4 — Level 2: Intermediate**

### 📖 Description

This project is a simple **Temperature Converter** developed as part of the Cognifyz Technologies Software Development Internship.

The program allows the user to enter a temperature and choose the direction of conversion:

* Celsius → Fahrenheit
* Fahrenheit → Celsius

The program uses functions, conditional statements, user input, and basic mathematical formulas to perform the conversion.

### 🎯 Objective

To create a temperature converter program that accepts a temperature from the user and converts it between Celsius and Fahrenheit.

### ⚙️ Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Interactive console-based interface
* Handles invalid conversion choices
* Handles invalid temperature input
* Displays the converted temperature up to two decimal places

### 🧮 Conversion Formulas

**Celsius to Fahrenheit:**

`F = (C × 9/5) + 32`

**Fahrenheit to Celsius:**

`C = (F − 32) × 5/9`

### 💻 Technologies Used

* Python 3
* Functions
* Conditional statements
* User input
* Exception handling

### ▶️ How to Run

1. Open a terminal in the `Task4_Temperature_Converter` folder.
2. Run the following command:

```bash
python temperature_converter.py
```

3. Select the conversion direction.
4. Enter the temperature.
5. The program displays the converted result.
